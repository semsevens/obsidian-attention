# 测试素材

给 Attention / Media Transcript 用的手测样本。整个文件夹可以随时删掉，
`.anno.json` 会跟着一起走。

| 文件                | 测什么                                                        |
| ----------------- | ---------------------------------------------------------- |
| `plain-note.md`   | 基本划线；重复短语的序号映射；跨格式选区的兜底；编辑后重锚                              |
| `含点的.文件名.md`      | sidecar 命名——含点文件名不能被当成 marker 剥掉                           |
| `周报.md`           | 中文文件名 + 中文正文的锚定与高亮                                         |
| `表格.md`           | **表格里的标注要即时生效** —— 实时预览把表格渲染成 CM6 widget，装饰打不进去，得靠 DOM 涂色补 |
| `编辑韧性.md`         | 原文被编辑后哪些标注还活着：前面插入 / 改写被标段落 / 整段删除 / 重复短语                  |
| `讲座.m4a`          | 音频播放（真实录音裁到 90 秒）                                          |
| `讲座.srt`          | 字幕轨 A —— 24 段，时间码有重叠（真实 ASR 输出）                            |
| `讲座.whisper.json` | 字幕轨 B —— 12 段，**分段边界和措辞都和轨 A 不同**，2 个 speaker              |

轨 A / 轨 B 刻意做得不一样：如果两条轨完全相同，跨轨重锚会平凡地成功，
测不出任何东西。在轨 A 上划线，切到轨 B，高亮应该靠时间戳 + 引用文本重新落位。
