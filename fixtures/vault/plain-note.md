# 普通笔记

这是一段普通的正文，用来测最常见的划线路径。选中这句话的任意一部分，
应该能弹出浮层、选色、留评论。

## 重复短语（测序号映射）

下面这个词会出现三次：**注意力**。

第一次：注意力是稀缺资源。
第二次：注意力被切碎之后很难重建。
第三次：注意力值得被记录下来。

在阅读模式里选中**第三个**「注意力」，高亮应该落在第三行，不是第一行。
这条路径没有源文件偏移可用，靠的是「屏幕上第几次出现 = 源文件里第几次出现」。

## 跨格式选区（已知限制）

这句话里有 **加粗的部分** 夹在中间。

从「这句话里有」一直拖选到「加粗的部分」，跨越了 markdown 标记，
源文件里不存在这个连续字符串 —— 应该弹 Notice 提示，而不是静默存一条错的。
在实时预览里选同样的范围则是正常的。

## 编辑后重锚

这一段是用来测锚点韧性的。先在这里划一条线，
然后在**本段之前**插入几行新内容，再切回来看高亮还在不在。
偏移会失效，但引用文本还在，所以应该自动跟过去。
