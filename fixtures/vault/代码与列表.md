# 代码块、列表、引用里的标注

普通段落先垫一行。

```ts
export function ownerOfMarks(mediaPath: string, trackPath: string): string {
  return trackPath.trim() !== '' ? trackPath : mediaPath;
}
```

- 列表第一项，标它
- 列表第二项，也标它
  - 嵌套的一项

> 引用块里的一句话，标注应该落在引用里而不是外面。

行内有 `代码片段` 和 **加粗** 和 *斜体*，跨着它们选一段试试——
存下来的是源码文本，画出来要跨多个文本节点。
