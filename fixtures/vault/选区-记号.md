# 选区与记号

屏幕上的字和源码里的字不一样的地方，都在这一篇里。拖选时可以跨过它们。

## 行内 HTML

公众号文章的脚注写成上标：第一处引用<sup>[1]</sup> 之后接着正文，第二处 <sup>[2]</sup> 也一样。

## 下划线与代码

配置项叫 tool_search，写成代码是 `tool_search`，私有字段是 `_meta`，关键字参数写成 `**kwargs`。

```js
if (result.exit_code !== 0) throw new Error(result.output);
const __dirname = path_join(a_b, c_d) * 2;
api.output(\`正在查询：${query}\n\`);
```

## 转义与字面星号

转义的 \*不是斜体\* 要原样显示。

****四个星号**** 会把外面两颗星号原样画出来。

计算 2 * 3 = 6 时，星号两边都是空格。

## 块级记号

- 列表第一项
- [x] 已完成的任务
1. 有序列表
> 引用里的一句话
> > 嵌套引用

## 跨段落

第一段写完了，最后一个字后面还有空白。

第二段很短。

第三段收尾，拖选可以从第一段中间一直到这里的句号之后。
